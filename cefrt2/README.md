# ChekiEdgeFit-RT v2

用于从照片中定位拍立得实例，并提取其外边框四角。算法由目标检测、提示式分割和几何拟合组成。

## 算法管线

```text
原图 → RT-DETR 检测 → 候选区域裁剪 → EdgeSAM 分割 → 边线拟合 → 原图四角
```

RT-DETR 找出各个拍立得实例的候选框；根据候选框裁剪局部区域，并将框作为提示交给 EdgeSAM 分割。随后从分割边界拟合边线、计算交点，再映射回原图，得到最终外框四角。

## 模型结构

### RT-DETR 检测器

- **卷积骨干网络**：采用 ResNet 提取多尺度图像特征。
- **混合编码器**：结合注意力与卷积融合不同尺度的信息。
- **Transformer 解码器**：通过目标查询预测各实例的位置框与置信度。

该模型负责区分实例并提供候选区域，不直接生成最终四边形。

### EdgeSAM 分割器

- **图像编码器**：采用轻量化 RepViT 提取局部区域特征。
- **提示编码器**：将检测框编码为定位提示，指定需要分割的实例。
- **Mask 解码器**：通过双向 Transformer 交互融合图像特征与提示，输出实例掩码。

该模型负责提取实例轮廓，最终四角由后续几何拟合得到。
