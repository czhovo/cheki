# ChekiEdgeFit-RT v2

## 整体框架

ChekiEdgeFit-RT v2 的模型部分采用“先检测、后分割”的串联结构。RT-DETR 在整张图片中定位拍立得实例，EdgeSAM 再对每个候选实例进行像素级分割。

```text
原图 → RT-DETR → 候选框 → 局部图像与框提示 → EdgeSAM → 实例掩码
```

检测框在两个阶段之间承担两项作用：确定局部图像的裁剪范围，以及为分割模型指定目标。裁剪时保留目标周围的上下文，框坐标也同步映射到局部图像中。这样，EdgeSAM 接收到的是“图像内容”和“要分割哪个实例”这两类信息。

两个模型的分工是：检测模型判断目标在哪里，分割模型判断哪些像素属于该目标。矩形检测框只是定位结果，不直接作为实例轮廓。

训练时，两个模型分别微调，并不通过整条管线联合反向传播。下文的“冻结”指本项目不再更新；它不表示这些模块从未经过预训练。

## RT-DETR 检测模型

检测器采用 RT-DETRv2，实现上延续了 [RT-DETR](https://arxiv.org/abs/2304.08069) 的卷积骨干、混合编码器和 Transformer 解码器结构。

**多尺度特征提取。** ResNet 骨干逐层提取图像特征，形成不同分辨率的特征图。较浅层保留更多边缘和位置细节，较深层提供更丰富的目标语义，这些特征共同用于识别和定位拍立得。

**特征交互与融合。** 混合编码器把同一尺度内的信息交互与不同尺度之间的融合分开处理：先在高层特征上使用自注意力联系不同空间位置，再通过卷积融合路径传递不同尺度的信息。输出特征同时包含局部细节和整图上下文。

**目标查询与框预测。** 解码器从编码后的特征中初始化候选目标查询，再通过注意力读取多尺度特征，逐步更新目标表示和位置。预测头为每个查询输出目标置信度和矩形框，符合筛选条件的候选框进入后续分割阶段。

### 各子模块如何训练

检测器以官方 COCO 预训练 checkpoint 初始化，再使用拍立得标注进行监督微调，不是只训练最后的检测头。

| 子模块 | 初始化与本项目训练方式 |
| --- | --- |
| ResNet 骨干 | 保留预训练权重，参与检测损失的联合反向传播，继续学习拍立得相关特征。 |
| 混合编码器 | 保留预训练的注意力、卷积和融合层，与骨干一起微调。 |
| Transformer 解码器 | 保留预训练权重，更新查询交互、跨尺度注意力及查询位置映射等模块。 |
| 分类输出头 | 为拍立得前景类别重新初始化，再用本项目的分类监督训练；训练用的去噪类别嵌入也相应重建并学习。 |
| 边框回归头 | 从预训练权重继续训练，通过框的位置和重叠关系学习定位。 |
| 正弦位置编码、参考锚点及有效区域标记 | 按既定规则生成，不属于通过梯度学习的参数。 |

**监督信号。** 将标注四边形在图像内的可见部分转换为轴对齐框，作为检测目标。训练时用 Hungarian 匹配分配预测与真实实例，再结合 VFL 分类损失、L1 和 GIoU 框回归损失更新网络；编码器和解码器中间输出保留辅助监督，并使用带噪标签与框进行去噪训练。上述损失共同作用于可训练模块，并非给每个模块单独训练一个任务。

## EdgeSAM 分割模型

[EdgeSAM](https://arxiv.org/abs/2312.06660) 保留了 SAM 的“图像编码器、提示编码器、掩码解码器”组织方式，并使用轻量化图像骨干。本算法将检测框作为提示，无需人工点击目标。

**图像编码。** RepViT 对裁剪后的局部图像提取特征，并融合不同层级的信息，得到保留空间布局的图像嵌入。这些特征描述局部区域的外观和边界，是后续掩码预测的基础。

**框提示编码。** 提示编码器将框的位置与角点信息转换为特征向量，用来指定当前关注的实例。框提供的是位置约束，具体哪些像素属于目标仍由模型结合图像内容判断。

**掩码解码。** 双向 Transformer 在提示特征与图像特征之间交换信息：提示从图像中读取相关内容，图像特征也根据提示进行更新。融合后的特征经过上采样和掩码预测头，生成对应实例的像素级掩码。

### 各子模块如何训练

分割器从官方 EdgeSAM 预训练权重开始，微调图像编码器和掩码解码器的主要部分，保留提示编码器与质量评分头。

| 子模块 | 初始化与本项目训练方式 |
| --- | --- |
| RepViT 骨干及特征融合层 | 从预训练权重继续更新，通过掩码损失学习拍立得的外观和边界。 |
| 提示编码器 | 沿用预训练模块，整体冻结，框提示编码不参与反向传播。其类型嵌入等已有预训练参数，位置编码基底本身则是固定缓冲。 |
| 双向 Transformer 与解码 token | 从预训练权重继续更新，学习图像内容与框提示之间的对应关系。 |
| 上采样层与 mask 预测头 | 参与微调，将融合特征转换为掩码；损失作用于选定的 mask 输出，其他输出没有独立监督。 |
| IoU 质量评分头 | 保留预训练权重并冻结，本项目不对它设置质量回归损失。评分头与参与注意力交互的 token 是不同部分。 |

**训练样本。** 框提示来自 cross-fitted 检测结果，即由没有使用该图片训练的折模型生成。用预测框裁剪局部图像，同时将对应 GT 外框变换到裁剪区域并栅格化为目标掩码。提示框不是直接拿 GT 框替代，因此分割器接触的是实际检测框带来的定位偏差。

**监督信号。** 使用 soft BCE 和 soft Dice 约束像素分类与区域重叠。梯度通过掩码解码器传回图像编码器，提示编码器和 IoU 评分头保持冻结。训练使用图像外观增强；BatchNorm 的运行统计量固定，但其可训练仿射参数仍可更新。这是本项目的监督微调，不是重新执行原论文的教师蒸馏流程。
